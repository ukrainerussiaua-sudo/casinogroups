# Игровой бот для групп: Дурак · Блэкджек · Покер · Тетрис

Пишешь в группе `игра дурак` / `игра блекджек` / `игра покер` / `игра тетрис` →
бот отвечает «команда создана» с кнопками **Зайти** и **Начать / Отменить** →
после старта новое сообщение «⚔️ Бой начался!» с упоминанием участников и кнопкой **Открыть бой** (Mini App).
Зрители открывают ту же кнопку и смотрят бой, но не видят карты в руках.

## Запуск
1. @BotFather → `/newbot` → токен.
2. `/setprivacy` → **Disable** (иначе бот не видит обычные сообщения в группе) — или сделай бота админом.
3. Нужен публичный **HTTPS**-адрес на порт 8080 (VPS + Caddy/nginx, либо `cloudflared tunnel --url http://localhost:8080`).
4. @BotFather → Bot Settings → **Configure Mini App** → вставь этот HTTPS-адрес
   (альтернатива: `/newapp`, и тогда задай `APP_SHORT_NAME` в окружении).
5. ```
   pip install -r requirements.txt
   BOT_TOKEN=... python main.py
   ```
6. Добавь бота в группу.

## Профиль, очки и звания
Всё хранится в локальной SQLite (`data/games.db`, файл создаётся сам). Команды работают в группе и в личке с ботом, регистр и знаки препинания не важны:

| Что написать | Что будет |
|---|---|
| `профиль`, `кто я`, `моя стата`, `мои очки`, `звание`, `мой ранг`, `мое место`, `/profile` … | карточка: очки, звание, игры/победы/поражения, винрейт, серия, значки + кнопка «Открыть профиль» (Mini App) |
| `профиль` ответом на чужое сообщение, `кто он`, `кто это`, `профиль @ник` | карточка другого игрока |
| `топ`, `рейтинг`, `лидеры`, `зал славы`, `/top` | топ-10 чата по очкам |
| `топ дурак`, `рейтинг по покеру` … | топ чата по победам в конкретной игре |
| `звания`, `как получить очки`, `/ranks` | список званий и правила очков |
| `помощь`, `команды`, `что умеешь`, `как играть`, `/help` | список команд |
| `/stopgame`, `стоп игра`, `отмена игры`, `отменить дурак`, `остановить игру` | остановить игру в чате (см. ниже) |
| `игра дурак`, `го в покер`, `давай сыграем в тетрис`, `поиграем в блекджек`, `/durak` … | создать игру |

## Остановка игры: `/stopgame`
Любой участник чата может остановить зависшее лобби или идущую игру: команда `/stopgame` (или фразы «стоп игра», «отмена игры», «отмена дурак»),
кнопка **🛑 Остановить игру** под сообщением «Бой начался» / «уже идёт игра», либо кнопка **✖️ Отменить** у лобби (если нажал не создатель).
1. Бот пишет «🛑 *имя* хочет остановить игру…» с кнопкой **↩️ Отменить отмену** и обновляет таймер каждые 15 секунд.
2. Если за **60 секунд** никто не нажал «Отменить отмену» — игра закрывается (очки и статистика не меняются), чат освобождается для новой игры.
3. Если кто-то нажал — игра продолжается, бот пишет *кто* отменил отмену. После этого 60 секунд новые отмены не принимаются.
Создатель ещё не начатой игры закрывает лобби сразу (кнопка «Отменить» или `/stopgame`). Если партия закончилась сама во время отсчёта — отмена снимается.
Время настраивается константами `STOP_TTL`, `STOP_TICK`, `STOP_COOLDOWN` в начале `bot.py`.

**Очки:** победа от +20 (+10 за каждого дополнительного соперника, делится на число победителей), поражение −10 (ниже 0 не падает), ничья +5, серия побед: с 3-й подряд +5, с 5-й +10.
**Звания:** 🥚 Новичок 0 · 🌱 Любитель 100 · 🎲 Игрок 250 · 🥉 Знаток 500 · 🥈 Мастер 900 · 🥇 Эксперт 1400 · 💎 Грандмастер 2100 · 👑 Легенда 3000.
После партии бот пишет в чат, кто сколько получил, и поздравляет с новым званием. Прерванные партии очки не меняют.
Правила и пороги — в `db.py` (`RANKS`, `WIN_BASE`, `LOSS`, …).

**Важно про хранение:** на хосте примонтируй постоянный том и укажи `DATA_DIR=/data` (или `DB_PATH`), иначе после редеплоя база пропадёт.

## Правила
- Дурак: подкидной, 36 карт, 2–6 игроков. Клик по карте = атаковать/подкинуть/отбиться. «Беру», «Бито», «Готово».
- Блэкджек: против дилера, 2–6 игроков, 5 раундов, ставка 100, стек 1000. Ещё / Хватит / Удвоить.
- Покер: Texas Hold'em, 2–6 игроков, стек 1000, блайнды 10/20 (растут каждые 6 раздач), сайд-поты. До одного выжившего.
- Тетрис: 2–4 игрока, общий seed, мусорные линии (2 линии → 1, 3 → 2, 4 → 4). Побеждает последний живой. Отсчёт 4 секунды начинается, когда **все** игроки открыли бой (пока кто-то не зашёл — «Ждём остальных…»).

## Структура
- `bot.py` — лобби, кнопки, остановка игры (`/stopgame`), WebSocket-сервер, проверка Telegram `initData` (HMAC).
- `games/` — серверные движки (durak, blackjack, poker, tetris). Каждый отдаёт `view(viewer)` — скрытые карты не уходят зрителям.
- `db.py` — SQLite: игроки, очки, звания, статистика, история. `commands.py` — разбор команд и синонимов. `texts.py` — тексты для чата.
- `webapp/index.html` — Mini App (одним файлом, без сборки), внутри — экран профиля и рейтинга.

## Ограничения v1
- Лобби и партии хранятся в памяти: после рестарта процесса активные игры пропадают.
- Одна активная игра на чат.
- Тетрис считается на клиентах (сервер доверяет доскам) — читерство возможно.
- Нет таймеров хода и кнопки «сдаться»; зависшую партию можно закрыть через `/stopgame`, а сама она закрывается через 15 минут неактивности.

## Деплой на хост
Нужен хост, который держит **долгий процесс** и даёт **публичный HTTPS-домен** (Railway, Render, Fly.io, VPS и т.п. — не serverless/Vercel).
- Переменная окружения: `BOT_TOKEN` (порт берётся из `PORT`, по умолчанию 8080).
- Команда запуска: `python bot.py` (есть `Procfile` и `Dockerfile`).
- Домен хоста вставь в BotFather → Configure Mini App. Проверка: `https://твой-домен/health` отвечает `ok`.
- Запускай ровно **один** экземпляр (лобби хранятся в памяти).
